Vision Skills is now open source.

It translates images into structured JSON for text-only LLMs that cannot process visual input natively. Objects, text, tables, code, spatial relationships, and semantic context — all extracted via Gemini free tier and delivered as structured data.

Integrates with OpenCode, Claude Code CLI, Cursor, Continue, GitHub Copilot, VS Code, Cline, Roo, Kilo Code, Codex CLI, and 9Router via MCP, CLI, REST, or SDK.

Setup: one free Gemini key + one config file. Setup scripts included.
